# smartkid.cc public sitemap

Hosted on GitHub Pages (not Vercel) because Google Search Console's sitemap fetcher has repeatedly failed to parse byte-identical XML served from Vercel edge (Last read set + "Sitemap could not be read").

Canonical GSC URL: https://sitemap.smartkid.cc/sitemap.xml

Regenerate from production: `curl -sL https://smartkid.cc/sitemaps/public -o sitemap.xml`
